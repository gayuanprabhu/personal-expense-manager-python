# Personal Expense Manager (Python Desktop App)

A simple and clean **Personal Expense Manager** built using **Python and Tkinter** to track daily expenses with real-time total calculation and basic expense management features.

This project focuses on usability, validation, and clean UI behavior rather than complexity.

---

## ✨ Features

- Add expenses with:
  - Description
  - Category
  - Amount
- Auto-generated date for each entry
- Expense list displayed in tabular format
- Delete selected expense with proper validation
- Real-time total expense calculation
- User-friendly warning messages
- Clean and minimal desktop UI
